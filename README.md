# Buriro Motors — Premium Car Showroom Website
A luxury automotive showroom website for **Buriro Motors**, a dealership specializing in new and used cars in Karachi, Pakistan.
## Live Demo
Open `public/index.html` in any modern browser, or visit the deployed preview.
## Built With
- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, flexbox, grid, and smooth transitions
- **Vanilla JavaScript** — No external libraries; custom carousel and scroll animations
## Highlights
- Responsive single-page design
- Custom hero image carousel with auto-play
- Scroll-triggered fade-up animations (Intersection Observer API)
- Animated stats counter
- Multi-section layout: Hero, Inventory, Financing, Services, Testimonials, Contact
